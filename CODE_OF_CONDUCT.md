# Code of Conduct

We want Plan It to be a friendly, harassment-free space for everyone.

**Expected:** be respectful, welcome different experience levels, give and accept constructive feedback, focus on what is best for the project.

**Not acceptable:** harassment, insults, personal attacks, discriminatory language, publishing others' private information, or other conduct that would be inappropriate in a professional setting.

Maintainers may remove or edit contributions that violate this, and may ban repeat offenders. Report issues by emailing samarthsharma9377@gmail.com. Reports are handled privately.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
